# Upstream resources

## Glastron signature

The loading screen uses the official website signature glyph (U+E90A):
https://www.glastron.com/us

The original website icon font, provenance, ownership notice and generated PNG
are in `assets/glastron/`. `main/glastron_logo.c` is generated by
`scripts/generate-logo.py`. This personal boat-display asset is not covered by
the LVGL or Barlow font licenses below.

## Waveshare hardware reference

Official board resources:
https://docs.waveshare.com/ESP32-S3-Touch-LCD-2.8C/Resources-And-Documents

Demo archive downloaded 2026-11-20:
https://files.waveshare.com/wiki/ESP32-S3-Touch-LCD-2.8C/ESP32-S3-Touch-LCD-2.8C-Demo.zip

`main/panel_init.h` contains the ST7701S register sequence extracted from
`ESP-IDF/ESP32-S3-Touch-LCD-2.8C-Test/main/LCD_Driver/ST7701S.c`.
The board pin map, timing, expander/reset assignments and SPI command protocol are
based on that example and the official schematic. Other board/runtime code is
implemented locally. The archive does not supply an explicit license file for
the Waveshare board code; no additional license grant is asserted here.

Regenerate the register table with `python3 scripts/import-panel-init.py DEMO.zip`.

## LVGL 8.3.11

https://github.com/lvgl/lvgl/tree/v8.3.11

Core sources, build support and Kconfig are vendored in `components/lvgl` under
the MIT license (`components/lvgl/LICENCE.txt`). Examples, demos and documentation
are omitted. The ESP-IDF branch of its root CMakeLists has been adapted to expose
this project's shared `lv_conf.h` and avoid dependencies on omitted example dirs.
Graphics source files are unchanged.
