# Glastron startup logo

The signature is the Glastron wordmark with the boat-shaped underline, taken from
the official Glastron website on 2026-11-20:

- Website: https://www.glastron.com/us
- CSS: https://www.glastron.com/Content/glastron/dist/glastron.min.css
- Icon font: https://www.glastron.com/Content/glastron/fonts/icomoon/fonts/icomoon.ttf
- CSS class: `icon-glastron-signature`; glyph U+E90A.

Glastron logo and related marks belong to their respective owners.
© 2026 Rec Boat Holdings, LLC Glastron, All Rights Reserved.
This asset is included for the user's personal boat display, not as a new logo.

`website-icons.ttf` is the original website font. `glastron-logo.png` and
`main/glastron_logo.c` are generated from its signature glyph by
`python3 scripts/generate-logo.py` (Pillow required for regeneration only).
The proportions are preserved; the display uses the white signature on black.
